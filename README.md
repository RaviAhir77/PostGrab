# PostGrab - Safe LinkedIn Visible Post Extractor (with Live Auto-Sync)

**PostGrab** opens directly **inside your LinkedIn page** as a persistent right-side companion drawer:
- **⚡ Real-Time Auto-Sync Engine**: Uses `IntersectionObserver` & `MutationObserver` to automatically detect when you scroll or when new posts load via infinite scroll — no manual refresh needed!
- **🟢 Live Sync Toggle Switch**: Easily pause or resume automatic scanning anytime with the toggle switch in the sidebar.
- **🔒 100% Height & Pinned to Right**: Takes 440px width and full 100vh height on the right side of LinkedIn.
- **Never Closes on Outside Clicks**: Click anywhere on the LinkedIn feed, scroll, or select text — the sidebar stays open consistently!
- **Floating Quick Toggle Tab**: A sleek `📑 PostGrab` badge on the right edge of your screen lets you open/close it with one click.
- **Safe & Passive**: Extracts only readable text from posts visible on your screen (zero images, zero bot calls).

---

## 🛡️ Built for Account Safety & Long-Term Stability

1. **Native Chrome Side Panel**:
   - Opens docked on the right side. It will **not close** when you click on LinkedIn, scroll, or switch between posts!
   - You can drag the left border to make it wider or narrower anytime.

1. **No Autogenerated / Hash CSS Classes**:
   - LinkedIn changes its hashed CSS classes (like `_709c7bd9`, `d053d6bb`) constantly.
   - PostGrab **never relies on these changing classes**. Instead, it uses official semantic attributes (`data-testid="expandable-text-box"`, `aria-label`, profile anchors, and semantic HTML `h2`) so the extension will not break when LinkedIn updates.
2. **Deterministic, Non-Changing Post IDs**:
   - Uses a deterministic hash of the author profile and text content. Post IDs remain 100% identical and stable whenever you view or reload them.
3. **Pure Text Content (Zero Images)**:
   - Only extracts readable post text, author name, contact emails, and job links. It avoids storing images or bloated media.
4. **Only Scans Visible Posts**:
   - Uses viewport coordinates (`getBoundingClientRect()`) to only extract the 2–3 posts currently visible in your browser window.
5. **Passive & Read-Only**:
   - Zero automated scrolling, zero network calls to LinkedIn servers, and zero bot tracking.

## 🚀 How to Install in Google Chrome / Brave / Edge / Kiwi

1. Open your browser and go to:
   ```
   chrome://extensions/
   ```
2. Enable **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked** (top-left) and select:
   ```
   D:\Good_code\extension
   ```
4. Click the puzzle icon 🧩 in the top toolbar and **Pin** 📌 **PostGrab**.

---

## 🦊 How to Install in Mozilla Firefox (Desktop)

1. Open Firefox and go to:
   ```
   about:debugging#/runtime/this-firefox
   ```
2. Click **"Load Temporary Add-on..."**.
3. Select the `manifest.json` file inside `D:\Good_code\extension`.
4. Open [LinkedIn](https://www.linkedin.com/feed/) and start using PostGrab!

## 💡 How It Works

1. Open your [LinkedIn Feed](https://www.linkedin.com/feed/) and scroll to any post you like.
2. Click the **PostGrab** icon in your toolbar.
3. PostGrab scans your viewport and presents the **2–3 posts visible on your screen**:
   - 👤 **Author Name & Profile Link**
   - ✉️ **Auto-detected Email** (e.g. `geeta.pokhariya@bigsteptech.com`)
   - 💼 **Attached Job Link** (if linked)
   - 📝 **Clean text content** (without images)
4. Click **"+ Save Post"** to save it to your local database (button updates to `✓ Saved`).
5. Open the **"Saved"** tab to search, review, or copy the content with **"📋 Copy Text"**.
6. Export your saved posts anytime to **CSV**, **TXT**, or **JSON**.
